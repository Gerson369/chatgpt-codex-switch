# Changelog

## v0.1.0 — 2026-11-20

First public Windows preview.

- Official browser/device-code login, encrypted local profiles and workspace-aware account identities.
- Manual account switching with Codex restart, encrypted recovery backup and explicit confirmation.
- Responsive three-column cards, search, keyboard navigation, notes and a dark scroll rail.
- Quota percentages/reset times from the native Codex app-server interface.
- Fixed Business response parsing on Chinese Windows by explicitly decoding UTF-8 process output.
- Portable executable, source build and synthetic/UI checks.

Known limits: unsigned build; Store Codex and file-based ChatGPT login only; quota tokens are not refreshed; app-server external-token integration is experimental; switching interrupts tasks.
